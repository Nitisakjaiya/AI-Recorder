# AI Recorder

ขลุ่ยรีคอร์ดเดอร์เสมือนที่เล่นผ่านเว็บแคม พร้อม AI ที่ฟังผู้เล่น เรียนรู้สไตล์ และแต่งท่อนตอบกลับเอง
(โครงงานคู่ วิชา REAI-401 Artificial Intelligence for Robotics)

## ติดตั้งและรัน

ต้องใช้ Python 3.10 และเว็บแคม

```bash
pip install -r requirements.txt
python ai_khaen.py
```

ทดสอบ AI โดยไม่ใช้กล้อง

```bash
python test_ai_musician.py
```

## ปุ่มควบคุม

| ปุ่ม | หน้าที่ |
| --- | --- |
| A หรือคลิกปุ่ม AI | เปิด/ปิด AI |
| M หรือคลิกปุ่ม MOUTH | สลับโหมดอ้าปากกับโหมดชูนิ้วอย่างเดียว |
| G / B | ให้คะแนนท่อนล่าสุดว่าชอบ / ไม่ชอบ |
| [ / ] | ลด / เพิ่มค่า temperature |
| F | สลับเต็มจอ |
| Q | ออกจากโปรแกรม |

## ไฟล์

- `ai_khaen.py` โปรแกรมหลัก: กล้อง นับนิ้ว ตรวจอ้าปาก เสียง และหน้าจอ
- `ai_musician.py` อัลกอริทึมตัดสินใจของ AI ใช้ต่อในโปรแกรมอื่นได้ เพราะไม่ขึ้นกับกล้องหรือเสียง
- `test_ai_musician.py` การทดสอบ AI 8 กรณี
- `recorder_note1.wav` ถึง `recorder_note9.wav` เสียงโน้ตทั้ง 9
